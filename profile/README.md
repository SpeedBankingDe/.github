# 🏦 SpeedBanking

Ultra-fast, zero-dependency Java tooling for **IBAN**, **BIC** and German bank account validation.

## Projects

- **[iban-commons](https://github.com/SpeedBankingDe/iban-commons)** — Ultra-fast, allocation-free, zero-dependency IBAN & BIC toolkit for Java 8+. Covers 127 countries, Android-compatible (API 21+). A modern, faster alternative to [iban4j](https://github.com/arturmkrtchyan/iban4j).
  - **[iban-commons-de-checkdigit](https://github.com/SpeedBankingDe/iban-commons/tree/master/iban-commons-de-checkdigit)** — verifies German domestic account number ("Kontonummer") check digits against a Bankleitzahl (BLZ), standalone module.
- **[iban-commons-benchmarks](https://github.com/SpeedBankingDe/iban-commons-benchmarks)** — JMH benchmarks comparing Java IBAN libraries (iban-commons, iban4j, jbanking, Apache Commons Validator, garvelink).
